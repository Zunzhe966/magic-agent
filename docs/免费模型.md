# OpenRouter 免费模型（清单 + 实测）

> 本文合并了原《免费模型清单》《OpenRouter 免费模型实测报告》。
> 数据文件：`docs/free_models.json`（由 `scripts/openrouter_free_models.py` 生成，`mcp/server.py` 读取）。
> 刷新清单：`python3 scripts/openrouter_free_models.py`
> 最后更新：2026-08-22

## 使用须知

- `:free` 模型有每日限额（账户未充值约 50 次/天；充值累计 $10 后提升到 1000 次/天）。
- 同一密钥下付费与免费混列，调用时以完整模型 id 为准（如 `deepseek/deepseek-r1:free`）。
- 免费模型上下文、质量差异大，按任务选择，长文优先选 context 大的。
- 分流已由域名规则 `openrouter.ai → 示例节点` 覆盖，使用这些模型无需额外配置。

## 一、实测结论（2026-08-22）

- **分流链路无问题**：mihomo 日志实锤，每次请求命中 `DomainSuffix(openrouter.ai)` 走代理出国。
- **密钥有效**：用量 $0，免费户无限额。
- **可用率**：14 / 19 个文本模型可用。
